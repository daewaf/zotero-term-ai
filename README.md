# 论文术语 AI 解释（Zotero Term AI）

在 Zotero PDF 阅读器中选中术语，点击「AI 解释」，将中文解释直接追加到高亮评论。使用你自己的 OpenAI 兼容 API 服务，无需额外 Python 服务。

## 功能

- 选区菜单提供 AI 解释；请求期间显示转圈，结束后恢复。
- 服务下拉选择；获取模型列表后支持搜索、选择，也可手动输入模型 ID。
- API 连接测试；密钥由 Zotero 登录凭据管理器保存。
- 高亮评论弹窗默认 16 px，支持 10–32 px、即时预览、应用和恢复默认。
- 保留原评论并追加解释；请求失败不写入解释。

## 兼容范围

本版声明支持 Zotero 10.0.x。0.2.8 功能在 Windows / Zotero 10.0.8 独立测试环境中完成过实机验证；0.2.9 整理发布与更新配置，未扩展兼容范围。macOS、Linux 以及其他 Zotero 版本尚未实机验证与测试。

## 安装与升级

1. 打开本仓库右侧 **Releases**，下载 `term-ai-版本号.xpi`。不要下载 GitHub 自动生成的 Source code 压缩包作为插件安装。
2. 在 Zotero「工具 → 插件」中选择从文件安装，或将 XPI 拖入插件窗口。
3. 升级后完整退出并重新启动 Zotero。

从正式 Release 安装的版本支持 Zotero 自动更新。旧版 0.2.8 使用无效占位更新地址，首次升级到本仓库版本须手动安装一次。插件 ID 沿用 `term-ai@local.research`，原有配置可继续使用。

## 首次配置

打开「工具 → 术语 AI · API 配置」，或「设置 → 术语 AI → 打开 API 配置」。

1. 选择服务；自定义服务填写 Base URL，通常以 `/v1` 结尾，也支持完整 `/chat/completions` 地址。
2. 输入自己的 API Key。没有密钥要求的本地服务可留空；已保存密钥时留空表示继续使用。
3. 获取模型列表后下拉选择，或手动输入模型名称。
4. 可选填写额外 JSON 参数；参数须由所选服务支持。
5. 确认数据发送与评论写入授权，点击「保存配置」。连接测试不代替保存。

仅支持 OpenAI 兼容的 Chat Completions 文本响应。云端接口要求 HTTPS，本机回环地址允许 HTTP。不内置 API 额度，调用费用由所选服务来决定。

## 使用与字号

在 PDF 中选中文字，点击「AI 解释」，等待转圈结束，然后打开高亮评论查看解释。也可对已有文字高亮/下划线使用插件提供的解释入口。

在「设置 → 术语 AI → 解释文字显示」输入 10–32 的整数字号，点击「应用字号」。插件配置窗口也可调整。字号影响高亮评论弹窗（包括普通评论），不改变 PDF 正文或已保存的评论文字。

AI 只获得选中文字及可选论文标题，不具备全文上下文；解释可能出错，请结合原文判断。

## 常见问题

- **模型列表获取失败**：服务可能不支持 `/models`；可直接手填模型 ID。
- **401 / 403**：检查对应地址的密钥和模型权限。
- **请求超时**：当前超时为 60 秒；确认服务可用后重试。
- **解释按钮报版本错误**：完整退出 Zotero，确认所有窗口已关闭后重启。
- **自动更新无效**：先手动安装本仓库发布的 XPI；仓库须有公开、非预发布且标记为 Latest 的 Release，其中包含 `updates.json`。

## 开发和发布

需要 Python 3.10+、Node.js 22，无须安装 npm 依赖。

```sh
node --test tests/core.test.cjs
python -m unittest discover -s tests -p "test_*.py"
python build.py --repository 你的GitHub用户名/仓库名
```

产物位于 `dist/`。构建时生成真实更新地址，不修改源码模板。详细步骤见 [发布指南](docs/PUBLISHING.md)、[更新日志](CHANGELOG.md)、[隐私说明](PRIVACY.md)。

反馈问题请在仓库 Issues 描述 Zotero 版本、操作系统、复现步骤和脱敏错误信息；不要提供 API Key、完整 Zotero profile 或论文原文。
